# v52 — правила для разработчиков модулей (внутренний документ)

Игра: Roblox «Miner Simulator» (v51). Исходники всех скриптов лежат в `src/` (имена как в Rojo:
`X.lua` — ModuleScript, `X.server.lua` — Script, `X.client.lua` — LocalScript). Мир строится
ПРОЦЕДУРНО кодом при старте сервера (`src/ServerScriptService/Modules/WorldBuilder.lua`).

## Жёсткие правила

1. Luau, первая строка `--!strict`. Комментарии в коде — НА РУССКОМ, короткие и по делу.
2. Весь текст, который видит игрок (вывески, подсказки, BillboardGui) — НА РУССКОМ.
3. Никаких внешних ассетов: нельзя `rbxassetid://`, MeshPart, Decal/Texture с картинками.
   Только `Part` (Block/Ball/Cylinder), `WedgePart`, `SpecialMesh` типа Sphere, материалы Roblox,
   встроенные текстуры частиц (`PartKit.TEXTURE_SPARKLE/FIRE/SMOKE`) и `rbxasset://sounds/...`.
4. Все цвета, размеры-настройки, длительности и цены — ТОЛЬКО в своём фрагменте конфига
   `config_parts/NN_имя.lua` (в нём пишутся строки вида `GameConfig.ИМЯ_РАЗДЕЛА = { ... }`,
   таблица `GameConfig` уже существует; `return` писать НЕЛЬЗЯ). Модуль читает значения через
   `local GameConfig = require(ReplicatedStorage:WaitForChild("Modules"):WaitForChild("GameConfig"))`.
   Файл `src/ReplicatedStorage/Modules/GameConfig.lua` — СГЕНЕРИРОВАННЫЙ (tools/assemble_config.py
   склеивает config_parts/*.lua), руками его не править. Чужие фрагменты и чужие файлы не трогать.
5. Детали собирать через `src/ReplicatedStorage/Modules/PartKit.lua` (прочитай его целиком):
   `PartKit.Block / Wedge / Cylinder / Ball / Ellipsoid / WeldTo / PointLight / SpotLight / Emitter / SurfaceLabel / Lighten / Darken`.
   По умолчанию деталь закреплена и БЕЗ коллизий; коллизию включать явно `{ CanCollide = true }`
   только там, где игрок должен упираться или ходить.
6. Производительность: не больше 6 источников света на постройку (Shadows = false), частицы с малым
   Rate (≤ 8/с на излучатель), никаких циклов RenderStepped/Heartbeat на сервере, никаких
   `while true do` без нужды. Геометрия детерминированная: `Random.new(seed)` из конфига.
7. Никаких TODO/FIXME, псевдокода и заглушек — модуль должен быть полностью рабочим.
8. В Output не должно быть ошибок: проверяй nil, не обращайся к несуществующим свойствам.

## Проверка

```
tools/check.sh <твои файлы .lua>
```
Запускает luau-lsp (проверка типов + линт с определениями Roblox). В ТВОИХ файлах должно быть
0 ошибок и 0 предупреждений. Ошибки в старых файлах (ProgressionUI, EquipmentBuilder и т.п.)
существовали до тебя — их игнорируй. Сообщения `TypeError` про твой файл — исправляй, а не глуши
через `:: any` без необходимости.

## Мир (координаты, studs)

- Земля: верх на Y = 0. Игроки: R15 и R6, рост ~5.5, прыжок ~7.2 в высоту.
- +Z — «юг» (к спавну), −Z — «север» (к шахте).
- Спавн: `GameConfig.SPAWN_POSITION = (0, 3.5, 22)`.
- Крестовина мостовой: 84×0.25×10 с центром (0, 0.12, 8).
- Щебёночная тропа к шахте: X ∈ [−5, 5], Z от 13.4 до −17.8, верх Y ≈ 0.45.
- Пункт продажи «$ SELL»: центр (−32, 0.25, 6). Магазин/рынок: центр `GameConfig.GREEN_SHOP_PAD_POS = (32, 0.25, 6)`.
- Ночной торговец: ларёк с центром (0, 0, 46), занимает X ∈ [−17, 14], Z ∈ [37, 50].
- Шахта — открытый карьер X ∈ [−60, 60], Z ∈ [−138, −18], низкий бордюр по краю; в южном бордюре
  проём X ∈ [−7, 7]. Арка входа: столбы X = ±10.5, Z = −12, высота до 15.4, вывеска на Y 16–22.
  Под землёй южнее карьера сплошная скала (Z от −18 до −6, Y от 0 до −186).
- Границы карты: X ∈ [−72, 80], Z ∈ [−150, 66].
